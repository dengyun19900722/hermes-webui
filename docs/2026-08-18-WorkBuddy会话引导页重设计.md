# WorkBuddy 会话引导页重设计

状态：已完成截图式实现；当前迭代为业务线 → 能力 → 技能/案例工作台

## 目标

将无消息的新会话从通用空状态改为 WorkBuddy 工作入口，帮助用户更快把“想做什么”转化为可执行任务：

- 顶部以业务线/Profile 分段控件切换智能体，默认以 `zk` 业务线为入口。
- 再选择与 Skills 面板一致的技能目录；目录来自 `GET /api/skills` 返回的 `category`，无技能数据时才回退到内置运维分类。
- 在所选能力下用左右双面板展示全量匹配技能和推荐最佳实践案例，让用户直接选择 `资产管理-主机发现` 这类任务入口。
- 保持现有三栏布局、Composer、工作区和 Skills 面板不变。
- 不自动创建会话、不自动发送消息，不改变会话持久化协议。

## 页面结构

引导页位于现有 `#emptyState` 内，仅在有可用工作区且当前会话没有消息时展示：

1. 顶部导航面板：使用与下方内容区一致的边框、圆角和背景，承载 WorkBuddy 标识、业务线/Profile 分段控件和 `运维智能体` 标题。
2. 技能目录标签区：优先展示当前 Profile 的技能目录分组，当前目录用主状态标记，并提供“字典管理”入口。
3. 左侧“技能”面板：展示当前能力下的全部可匹配技能，包含数量、图标、名称、描述和进入箭头。
4. 右侧“最佳实践案例”面板：展示当前能力下的 2 个推荐案例，存在更多案例时可用隐藏的刷新按钮轮换。

无工作区时继续由 `workspace_empty.js` 渲染创建工作区状态；用户关闭空状态建议时隐藏案例区，但保留技能区。

## 数据与交互

- 智能体数据读取现有 `GET /api/profiles`；点击智能体调用现有 `switchToProfile()`，不新增 Profile 协议。
- 技能数据读取现有 `GET /api/skills`，因此遵循当前 Profile 的技能边界，不新增技能启动接口。
- `default`/根 Profile 且存在 `zk` 时，启动后延迟切换到 `zk`，避免抢跑正常 boot 的 active-profile 初始化。
- 智能体、技能目录和已知技能名称/描述统一从前端 `GUIDE_TRANSLATION_DICTIONARY` 取中文/英文文案，并提供页面内“字典管理”入口，可编辑当前浏览器中的智能体、目录和技能中文映射。
- 字典管理弹窗支持按智能体、技能目录、技能类型筛选，并支持按原文、中文名称和描述即时搜索。
- 首次进入时 Profile 与 Skills 请求并行发起；技能数据返回前显示加载态，返回后立即展示真实目录和技能，避免先显示“0 个技能”或静态默认案例。
- 技能按内置 ZK 运维能力映射和关键词归入能力分类；当前能力下不再截断技能数量，确保 Profile 范围内的匹配技能全量可见。
- 案例可把同一个底层技能作为不同能力的入口；推荐区默认展示 2 个案例，以保持首屏密度接近运维工作台。
- 已停用技能显示“已停用”并不可点击。
- 点击技能或案例只在 Composer 中加入命名技能上下文 chip，并按模板预填 `#msg`，触发输入同步和自动高度调整，不调用发送逻辑。
- 技能启用/停用、保存、删除和 Profile 切换后刷新引导页缓存，避免首屏显示过期技能。
- 文案随现有 `<html lang>` 更新，当前覆盖中文和英文，不新增全量 i18n key。

## 响应式策略

- 宽屏聊天区使用左右双面板布局：技能在左，最佳实践案例在右。
- 窄屏聊天区切换为单列布局。断点使用 `900px`，覆盖左侧导航在平板宽度仍可见、导致聊天中心实际变窄的情况。
- 技能卡片和案例卡片在移动端保持紧凑布局，页面整体不滚动；顶部和双面板使用统一边框，技能面板和最佳实践案例面板分别承载内部滚动，Composer 保持现有底部固定行为。
- 页面不产生引导页自身的横向滚动；右侧工作区面板的隐藏布局宽度属于现有页面行为。

## 实现范围

- `static/index.html`：增加引导页结构和脚本入口。
- `static/session_guide.js`：负责文案、Profile 加载、能力分类、技能/案例卡片、Composer 预填和缓存刷新。
- `static/messages.js`：允许外部代码创建带自定义名称的 Composer 上下文 chip。
- `static/style.css`：增加 launchpad 视觉和响应式规则。
- `static/workspace_empty.js`：无工作区渲染时移除引导页状态类。
- `static/panels.js`：技能变更和 Profile 切换后通知引导页刷新。
- `tests/test_session_guide_static.py`：覆盖 DOM 钩子、API 契约、兼容状态、响应式规则和 JS 语法。
